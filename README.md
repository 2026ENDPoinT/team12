# 사이 (SAI)

사이(SAI)는 서울과학기술대학교의 건물 입구부터 미래관 안의 호실까지 안내하는 3D 캠퍼스 길찾기 서비스입니다.

- **캠퍼스 길찾기** · 건물과 출입구를 3D 지도에서 확인하고, 빠른 길이나 계단 없는 길을 선택할 수 있습니다.
- **길 막힘·지름길 제보** · 이용자가 공사로 막힌 길이나 새 지름길을 제보하면, 관리자가 확인한 뒤 경로에 반영합니다.
- **미래관 실내 안내** · 층별 도면에서 호실을 검색하고, 경로를 미리 걸어보거나 카메라 화면 위에 표시되는 AR 안내를 따라갈 수 있습니다.
